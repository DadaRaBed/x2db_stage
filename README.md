# Data Manager

Application desktop de gestion de bases SQLite et d'importation de fichiers Excel.

## Fonctionnalités prévues

- Authentification avec SQLite
- Importation `.xls` et `.xlsx`
- Glisser-déposer et sélection classique de fichiers
- Suppression automatique des colonnes `Unnamed`
- Conversion vers des types statiques
- Création et gestion de bases SQLite
- Recherche et filtrage
- Détection des doublons
- Statistiques sur les colonnes
- Exportation Excel, CSV et SQL
